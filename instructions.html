Insights Publishing Instructions

How to write an Insights article, use the Insights Creator, and publish it to the ARG Naples website. Run on a private computer only (python3 -m http.server) — these tools are not deployed to the public site.

Overview

Publishing a new Insights article takes three main steps:

  1. Create — write the article in the Insights Creator tool.
  2. Download — get a ZIP package with the article page, images, and a listing snippet.
  3. Publish — add the files to the website project, paste the snippet into blog.html, and push to Git so Netlify updates the live site.

You do not need to write HTML by hand. The tool builds the article page for you using the same layout as existing Insights posts.

Open the Insights Creator

The creator runs locally on your computer — it is not on the public website.

  1. Open Terminal (Mac) or your command line.
  2. Go to the website project folder. For example: 
    cd /path/to/giacalone
  3. Start a local server: 
    python3 -m http.server
  4. In your browser, open: 
    http://localhost:8000/insightsCreator.html
Open Insights Creator

Keep Terminal running while you work. When you are done, you can stop the server with Ctrl + C.

Write your article

Step 1 — Article text

Either drop a Word file (.docx) into the upload area, or paste / type your article in the text box.

  • First line = headline (filled in automatically in Step 3).
  • Second line (optional) = subheadline — a short line under the headline.
  • Separate paragraphs with a blank line.
  • Use ## Heading for section headings and ### Subheading for smaller headings.
  • Use > Quote text on its own line for a pull quote (blockquote).

Example article structure

Record-Breaking Sale in Port Royal
What this means for Naples luxury buyers

headlineImage="port-royal-sunset.jpg"

When a single transaction resets the ceiling for an entire market, the reverberations are felt far beyond the closing table.

## Why This Sale Matters

Port Royal has long been the most prestigious address in Southwest Florida.

inlineImage="market-chart.png"

addCta title="Request A Private Market Evaluation"

Step 2 — Photos (optional)

Drop JPG, PNG, or WEBP files into the photo area. Keep the original file names — you will reference them in your article text.

Step 3 — Review

The tool auto-fills headline, subheadline, date, read time, category (guessed from your text), excerpt, and file name. Author is remembered from your last session. Edit anything that needs changing, then click Refresh preview.

Your author choice is remembered for the next article.

Formatting reference

These special lines go on their own line in your article text (except inline links, which go inside a sentence). Put a blank line before and after images and CTAs so they appear in the right place.

What you type What it does
subheadline="Your subtitle" Subheadline under the main headline (optional if you use the second line of your article instead).
headlineImage="photo.jpg" Wide banner image under the title — same style as existing Insights posts.
inlineImage="photo.jpg" Smaller centered image inside the article body.
headlineImage="https://…" Use a web image URL directly (no upload needed).
[link text](page.html) Inline hyperlink inside a paragraph. Example: [Port Royal](communities/port.html)
hyperlink label="…" url="…" Standalone link on its own line. Use url="#pme-request" to open the private market evaluation form.
addCta title="…" Centered navy button with your title as the label. Clicking opens the Request A Private Market Evaluation modal (same as the main site). You only need the title.
## Section title Section heading (H2).
### Subsection title Smaller heading (H3).
> Pull quote Highlighted blockquote.

Image file names

  • Local images must match a file you dropped in Step 2 (saved to the assets/ folder).
  • If an image file is missing on the live site, nothing is shown — no broken image icon.
  • The headline image also appears on the Insights listing card in blog.html.

Add photos

  1. Drop images into Step 2 before downloading the ZIP.
  2. Use the exact file name in headlineImage= or inlineImage=.
  3. Wide landscape photos work best for headlineImage.

Preview tip: Drop images in Step 2 for the ZIP package. If the file is already in the project assets/ folder on your machine, preview can show it too — use the exact file name in headlineImage="…" (straight quotes, on its own line).

Review and download

  1. Check headline, subheadline, author, date, category, and the short blurb in Step 3.
  2. Click Refresh preview and scroll through the article. Test any addCta buttons — they should open the private market evaluation modal.
  3. Click Download ZIP package. You get a file named like insight-your-headline-202606-package.zip.
  4. Optionally click Copy listing snippet — you will need this for blog.html.

The ZIP contains:

  • Insights/your-article.html — the full article page
  • assets/ — your uploaded photos (shared site folder)
  • -LISTING-SNIPPET.txt — card HTML for blog.html (links to Insights/…)

Folder layout: blog.html = Insights listing (stays at site root). Each new post = one file inside Insights/.

Publish to the live site

  1. Unzip the package into the website project folder — the same folder that contains blog.html and index.html. Merge the assets/ folder if one already exists.
  2. Add the listing — open blog.html in a text editor. Find <div class="blog-grid"> and paste the listing snippet at the top (it uses the featured card layout for the newest post).
  3. Commit and push so Netlify can deploy the update.

Using Terminal (Git)

From the project folder:

git add .
git commit -m "Add Insights: Your headline here"
git push

The live site usually updates within a few minutes after the push completes.

What gets published: the new .html article file, any new images in assets/, and the updated blog.html listing.

Using GitHub Desktop

If you prefer not to use Terminal for Git:

  1. Unzip the package into the project folder.
  2. Paste the listing snippet into blog.html.
  3. Open GitHub Desktop — you should see the new and changed files listed.
  4. Write a summary such as Add Insights: Your headline here.
  5. Click Commit to main (or your branch), then Push origin.

Troubleshooting

Problem What to do
Word file won’t load Save as .docx or copy/paste the text into Step 1 instead.
No images in preview Drop the images in Step 2 first, then click Refresh preview.
CTA button doesn’t appear Put addCta title="…" on its own line. Click Refresh preview.
Article page works but not on Insights list Paste the listing snippet into blog.html inside blog-grid.
Broken image on live site Check the file name matches exactly and the image was included when you unzipped into assets/.
Changes not on live site yet Confirm git push finished. Netlify may take a few minutes to deploy.
Creator page won’t open Make sure python3 -m http.server is running and you use localhost:8000.
