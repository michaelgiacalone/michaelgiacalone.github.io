# How to view the site locally

**Don’t open HTML files by double‑clicking** (`file:///...`). Use a local web server from the project root:

```bash
python3 -m http.server 8000
```

Open **http://localhost:8000**

Footer subscribe and the PME modal post leads directly to IDX — no Netlify or other backend needed.

## Internal editor tools

`insightsCreator.html` and `instructions.html` are for publishing Insights articles on your machine only.
